# Transient-Diffusion1D-FDM-Explicit-Solvers-Cpp
A modular C++ finite difference solver for the 1D transient diffusion equation with explicit schemes.

## Project Information
- **Date:** 2026-08-07
- **Author:** Amir Asgharnia
- **Environment:** Linux Mint (GCC, GNU Make, GDB, VS Code)
- **Repository:** [Transient-Diffusion1D-FDM-Explicit-Solvers-Cpp](https://github.com/AmirAsgharniaME/Transient-Diffusion1D-FDM-Explicit-Solvers-Cpp)
